# Surya Pratap Singh - Portfolio

A minimal, modern portfolio website showcasing full-stack development skills, projects, and certifications.

## Features

- Responsive design for all devices
- Smooth animations and transitions
- Clean white color scheme with dark background
- Interactive navigation and typing effects
- Contact information cards
- Project showcase section
- Skill progress bars
- Certification display

## Tech Stack

HTML5, CSS3, JavaScript (Vanilla), Google Fonts (Orbitron, IBM Plex Mono)

## Project Structure

index.html - Main HTML file with all sections
style.css - Complete styling and animations
script.js - JavaScript for interactivity
profile.png - Profile image
resume.pdf - Resume file

## Sections

Navigation - Fixed navbar with logo and menu
Hero - Title with glitch effect, typing animation, CTA buttons
About - Profile, introduction, details, education
Skills - Programming, web development, databases, tools
Projects - Workit freelance marketplace project
Certification - C++ Programming certification
Contact - Phone, email, social links, resume download
Footer - Copyright and links

## Getting Started

1. Clone the repository
   git clone https://github.com/Surya1087/portfolio.git

2. Navigate to project directory
   cd portfolio

3. Open index.html in browser or use Live Server extension in VS Code

4. Live Server: Right-click index.html and select "Open with Live Server"

## Customization

To update personal information:
- Edit index.html and change name, title, bio, skills, projects, contact details
- Replace profile.png with your profile picture
- Replace resume.pdf with your actual resume

To change colors:
- Open style.css
- Modify :root CSS variables for primary, secondary, background colors

To modify animations and interactions:
- Edit script.js
- Change typing phrases in the phrases array
- Customize scroll effects and animations

## Responsive Breakpoints

Desktop: 1200px and above
Tablet: 768px to 1199px
Mobile: Below 768px
Small Mobile: Below 480px
